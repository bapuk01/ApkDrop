# ApkDrop

**English:** send APK files from a Windows PC to Android phones and Android TV over Wi-Fi and install
or update them instantly. Drag an APK into the window and it is installed on the phone. The PC app can
also watch your build folders and push every new build to the chosen devices automatically. No cables,
no adb. Interface in English and Russian, light and dark theme. Download `ApkDrop.exe` and
`ApkDrop-android.apk` from [Releases](../../releases).

---

Отправка APK с ПК на Android-телефон по Wi-Fi и мгновенная установка или обновление.

- `android/` — приложение для телефона и Android TV: принимает APK и ставит его через PackageInstaller.
- `pc/` — приложение для Windows (.NET 8, WinForms): находит телефоны в сети и отправляет APK.
- `docs/` — исходник PDF-инструкции.
- Готовые сборки (`ApkDrop.exe`, `ApkDrop-android.apk`, PDF-инструкция) — в разделе
  [Releases](../../releases).

## Первый запуск

1. Установите `ApkDrop-android.apk` на телефон (через USB `adb install` или просто скопировав файл).
2. Откройте ApkDrop на телефоне и выдайте разрешения из блока «Настройка»:
   - **Установка приложений** — обязательно;
   - **Работа в фоне** — чтобы сервер не засыпал.

   Когда ApkDrop свёрнут, запрос «Установить» приходит уведомлением. Если держать ApkDrop открытым,
   окно установки появляется само.
3. Запустите `ApkDrop.exe` на ПК. Он сам найдёт телефон в сети (или добавьте его по IP с экрана телефона).
   При первой отправке введите PIN с экрана телефона. PIN сохранится.

## Работа

- Перетащите `.apk` в окно — он сразу уйдёт на отмеченные телефоны.
- **Следить за файлом**: укажите `app\build\outputs\apk\debug\app-debug.apk` — каждая новая сборка
  (Build → Build APK или `gradlew assembleDebug`) будет ставиться на телефон автоматически.
- `ApkDrop.exe путь\к\файлу.apk` — отправить сразу при запуске (удобно для «Открыть с помощью»).
- Без ПК-приложения: `curl -T app.apk -H "X-Pin: 123456" http://<ip-телефона>:8765/install?launch=1`

## Автообновление по списку

Вкладка «Автообновление» на ПК — список приложений, за версиями которых следит ApkDrop.

- **Добавить APK…** — источник — конкретный файл; **Добавить папку…** — папка со сборками
  (например `app\build\outputs\apk\release`), берётся APK с наибольшим versionCode. Папки `intermediates`
  пропускаются. Можно просто перетащить файл или папку на эту вкладку. Если в папке несколько
  разных приложений, каждое добавится отдельной строкой.
- Проверка идёт при каждом изменении файлов в источниках и раз в 2 минуты. Так телефон, который
  был вне сети, получит обновление, когда вернётся.
- **Что считается новой версией:**
  - сборка с бо́льшим versionCode;
  - сборка с **тем же versionCode, но другим содержимым**, собранная позже последней установки
    на телефоне. Телефон сообщает хеш установленного APK, нужен ApkDrop 1.3+. Условие «позже
    установки» не даёт откатить то, что вы поставили, например, из Android Studio кнопкой Run.
- **Старый ApkDrop на телефоне** (до 1.3) не сообщает хеш установленных APK. ПК обновляет его сам, до
  проверки приложений. Сборку берёт из списка автообновления или из `ApkDrop-android.apk` рядом с
  `ApkDrop.exe`. Обновление только поверх уже установленного ApkDrop.
- В заголовке окна видны версия и дата сборки ПК-клиента. Запускайте `dist\ApkDrop.exe`.
- **Подпись.** Если в папке лежат сборки с разными ключами (debug и release), на каждый телефон идёт
  новейшая сборка **с той же подписью, что у установленного приложения**. Android не принимает
  обновление с другой подписью. Если свежая сборка подписана другим ключом, в журнале будет
  предупреждение. Чтобы перейти на неё, удалите приложение на телефоне.
- **Телефоны…** (кнопка, двойной щелчок или правый клик по строке) — для каких телефонов ведётся приложение:
  - *все телефоны, отмеченные галочкой* в главном списке (по умолчанию);
  - *только выбранные* — свой набор телефонов для каждого приложения. Галочка в главном списке
    на него не влияет;
  - *устанавливать, если приложения ещё нет* — без этой опции приложение только обновляется там,
    где уже стоит. С ней оно ставится на выбранные телефоны, где его нет. Первая установка —
    одно нажатие «Установить» на телефоне.
  Можно выделить несколько приложений и задать им одну настройку сразу.
- Колонка «Для телефонов» показывает фильтр, «На телефонах» — версию и состояние на каждом телефоне.
- Если телефон отклонил обновление (нажали «Отмена», не подтвердили за 5 минут, конфликт подписи),
  эта версия больше не предлагается ему автоматически. Повторить — кнопка **Проверить сейчас**.
- Фоновая проверка работает только с телефонами, для которых сохранён PIN. Она никогда не
  спрашивает PIN сама.
- Правый клик → «Показать APK в Проводнике».
- Для автообновления нужна версия ApkDrop на телефоне 1.1 или новее. Самого ApkDrop тоже можно
  добавить в список, тогда телефоны будут обновлять и его.

## Язык и тема

- **ПК:** кнопка «⚙ Язык и тема» справа вверху окна. Язык: как в Windows, русский или English.
  Тема: как в Windows, светлая или тёмная. После выбора программа перезапускается. Если в этот
  момент идёт отправка, настройка применится при следующем запуске.
- **Телефон и TV:** язык берётся из системы. На Android 13+ его можно задать отдельно для ApkDrop:
  «Настройки → Приложения → ApkDrop → Язык».
- Сообщения об установке телефон присылает на языке ПК-клиента, поэтому журнал на ПК не смешивает
  языки.

## Android TV

ApkDrop ставится и на Android TV. Он виден в лаунчере TV с баннером, его можно добавить в избранное
на главный экран. Управлять можно пультом, элемент в фокусе обведён рамкой.

- «Запускать приложение после установки» работает и для приложений, у которых есть только значок
  для TV.
- Разрешение «Установка неизвестных приложений» на TV обычно находится в «Настройки → Настройки
  устройства → Безопасность и ограничения → Неизвестные источники». На некоторых TV отдельного
  экрана «Батарея» нет. Тогда кнопка «Разрешить» открывает карточку приложения в настройках.

## Портативный режим

Если рядом с `ApkDrop.exe` лежит `settings.json`, настройки берутся и сохраняются там, а не в
`%APPDATA%\ApkDrop`.

## Тихие обновления

- **Android 12+**: приложение, которое уже установлено *через ApkDrop*, обновляется без вопросов.
  Первая установка всегда требует одного нажатия «Установить» — это ограничение Android.
- Если приложение последний раз ставилось не через ApkDrop (например, из Android Studio по кнопке Run),
  следующее обновление через ApkDrop попросит подтверждение, а дальнейшие пройдут тихо.
- **Android 8–11**: каждую установку нужно подтверждать на телефоне.
- Обновить можно только APK с той же подписью и versionCode не ниже установленного.
  Иначе ApkDrop сообщит причину — в этом случае удалите приложение на телефоне.

## Сеть

- TCP 8765: HTTP API (`/info`, `/auth`, `/install`); UDP 8766: поиск телефонов.
- ПК и телефон должны быть в одной сети. В гостевых Wi-Fi сетях и сетях с изоляцией клиентов
  устройства не видят друг друга.
